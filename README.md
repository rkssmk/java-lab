# Java Lab v3.2

Персональная учебная площадка по двум согласованным планам подготовки Java. Основная карта курса сохранена: 7 блоков и 72 урока. В этом обновлении полностью выровнен первый блок: **12 уроков, ровно 2 активные задачи на урок**.

## Что сделано в v3.2

- Для каждого из 12 уроков первого блока опубликованы подробные учебные материалы: объяснение простыми словами, пошаговый пример, причины выбора конструкции, частые ошибки и план решения.
- У каждого урока ровно 2 активные практические задачи. Две старые задачи (обмен значений и частота символа из контрольной) сохранены в разделе исторических упражнений вместе с их статусами и попытками, но не считаются активными задачами.
- Каждая активная задача имеет точное условие, стартовый код Java, автоматические тесты, три ступени подсказок, пошаговый разбор, таблицу ручного прогона, типичные ошибки и эталонное решение.
- В блоке 1 теперь 24 активные задачи и 90 автоматических тест-кейсов. Эталонные решения всех 24 задач скомпилированы на JDK 21 и успешно прошли все 90 тестов.
- В уроках 1–3 добавлены автоматические вопросы на понимание. Чтобы завершить незавершённый урок, нужно набрать минимум 2 из 3 (для контрольной урока 12 — 3 из 3), пройти автоматические тесты обеих задач и не иметь незакрытого повтора.
- Чтение теории и ручное изменение статуса не засчитывают упражнение. У каждой задачи активен только автоматический зачёт по тестам. Если открыть подсказку даже после уже успешной попытки, статус меняется на «С подсказкой» и назначается повтор без помощи; старый успешный тест не позволяет обойти повтор.
- При использовании подсказки задача планируется на повтор через 2 дня. Просмотр разбора архивирует прежний черновик и не засчитывает задачу. После повтора тесты нужно пройти заново с чистого черновика без подсказок.
- В исходной карте курс контрольной 12-го урока описан как три задачи, но по твоему более позднему требованию в Java Lab оставлены ровно две активные задачи на урок; название контрольной обновлено соответственно, а прежнее упражнение сохранено в архиве. Первая попытка каждой задачи выполняется без подсказок; после неудачной проверки становятся доступны три ступени помощи и разбор. Для зачёта нужен самостоятельный повтор.
- Черновики, результаты тестов, заметки, попытки, статусы уроков и очередь повторения сохраняются в localStorage браузера. Сохранился тот же ключ данных и адрес `http://127.0.0.1:8765/`, поэтому обновление не должно сбросить прежний прогресс. Перед обновлением всё равно рекомендуется сделать экспорт резервной копии.

## Важное уточнение по восстановленным упражнениям

В старой переписке сохранились названия некоторых ранних упражнений, но не полные исходные условия. Поэтому для «Расчёта чека», «Работы с балансом» и «Погашения долга» добавлены новые однозначные учебные формулировки, явно описанные как обновлённые/восстановленные версии. Исторические статусы и заметки не подменяются утверждением, что это в точности старые условия. Для задачи с нулями в числе тест `505` ожидает результат `1`; прежняя попытка остаётся в статусе «Повторить», пока ты не пройдёшь проверку.

## Запуск на Windows

1. Перед обновлением открой старый сайт и нажми экспорт резервной копии в правом верхнем углу.
2. Закрой старое окно Java Lab Server.
3. Распакуй весь архив в новую папку.
4. Запусти `start.bat` двойным щелчком.
5. Открой `http://127.0.0.1:8765/` в том же браузере, где занимался раньше.
6. Не закрывай окно сервера во время занятий.

Тебе ранее удавалось запустить Java 25. Эта версия подходит для локального статического сервера.

## Автоматическая проверка Java-кода

Для проверки упражнений используется внешний Judge0 CE (Java language ID 62). Нужны подключение к интернету и доступность сервера; при необходимости в разделе «Практика» можно указать другой HTTPS endpoint и токен. Код отправляется внешнему сервису для компиляции и выполнения в изолированной среде. Не вставляй секреты или пароли в редактор. Сам сайт не компилирует Java локально.

## Сохранение и перенос данных

- Данные хранятся в браузере на этом компьютере и для этого адреса. Они сохраняются после закрытия вкладки и браузера, но не синхронизируются автоматически с другими устройствами.
- Перед удалением данных браузера или переносом на другой компьютер используй экспорт. На новом устройстве открой тот же сайт и импортируй JSON-файл через кнопку со стрелкой вверх.
- v3.2 использует прежний ключ localStorage, поэтому при запуске на прежнем `localhost:8765` имеющиеся заметки, черновики, уроки и попытки мигрируют автоматически.
